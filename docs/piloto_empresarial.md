# Propuesta de piloto empresarial

## Problema que resuelve hoy

Los equipos que modelan consumos necesitan saber si un balance es consistente y poder justificar sus números. Matrix Studio permite introducir el sistema, detectar contradicciones, explorar escenarios y conservar el procedimiento completo para revisión técnica.

## Demostración sugerida

1. Cargar los datos originales y observar la incompatibilidad entre el vector esperado y las capacidades.
2. Mostrar el determinante, la producción negativa y su consecuencia operacional.
3. Abrir la variante compatible y verificar los tres métodos.
4. Reducir la resina a 100 kg para analizar el cambio en la solución.
5. Introducir filas dependientes y explicar los dos diagnósticos de singularidad.
6. Descargar el informe con entradas y resultados verificables.

## Criterios de aceptación de un piloto

- Acordar unidades, escala, supuestos de continuidad y responsables de los datos.
- Contrastar escenarios históricos con resultados del equipo de operaciones.
- Exigir concordancia entre métodos y error por componente dentro de la tolerancia convenida.
- Registrar cada entrada junto con su informe para poder repetir el análisis.
- Diferenciar una igualdad algebraica de una decisión aprobada de producción.

## Evolución fuera del alcance actual

La implementación actual no incluye autenticación, almacenamiento multiusuario, integración con ERP, auditoría persistente ni optimización de costos o beneficios. Esas funciones requieren requerimientos y datos del cliente. Si se busca un plan rentable con capacidad ociosa o unidades enteras, habrá que ampliar el modelo a programación lineal o entera y validar sus supuestos.

No se prometen ahorro, retorno financiero, aprobación industrial ni una venta: no se dispone de evidencia comercial. La entrega ofrece una base funcional y demostrable para evaluar ese siguiente paso.
